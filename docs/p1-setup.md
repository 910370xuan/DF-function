# 第一階段：出貨單／貨運單自動產檔 — 安裝與測試

這一版只做**產生可以列印的出貨單與貨運單**，不碰庫存，也還沒串接 LINE。
訂單先填在「出貨清單」工作表；之後串好 LINE，系統會自動填進同一張表。

## 會做什麼
- **每個出貨日 10:00**（每 5 分鐘檢查一次，最晚 10:05 執行）：
  - 收集「出貨清單」中狀態為 `待出貨`、出貨日在今天以前的訂單，每家店一張出貨單。
  - 輸出：
    - 出貨單 PDF：每家店一頁（第一聯＋第二聯在同一頁）
    - 出貨單 Excel
    - 貨運單 PDF：每頁 3 家，例如 8 家 → 3 + 3 + 2
  - 用 Email 寄出 PDF；如果沒有訂單，會寄「今日無待出貨訂單」。
- **10:00 之後、16:00 之前**：有新的今天出貨訂單時，寄一封 Email 詢問「是否需要補單？」（同一批訂單只問一次）。
  - 要補單：在「設定」工作表勾選「產生補單（勾選執行）」（手機上也可以），或用選單「華暉出貨 → 產生補單」。
  - 只有一單、要自己手打：把狀態改成 `已手打`，並把「單據編號最後流水號」加 1。
- **單據編號**：`20B` + 年份字母（2026=F、2027=G）+ 月份 2 碼 + 流水號 9 碼；每個月重新從 1 開始。
- **10+1**：同一天出貨、同一家店的同型號會先合併成一行，再依合併後的數量計算每 10 個送 1 個（不同品項不混算），附註自動寫成 `10+1`、`20+2`。DCB-6000 填了 8pin 數量的話，會寫成 `10+1/8P*2`。
- **資料有誤**（店家不在清冊、型號不對、數量不是整數、超過 7 行）：那一筆不會產單，原因寫在「系統訊息」欄，Email 也會列出來。
- PDF、Excel 和產單用的試算表都存在指定的雲端硬碟資料夾，**不會覆蓋舊檔**。每次批次都會記錄在「批次紀錄」工作表。

## 安裝步驟（約 20 分鐘）
1. 在 Google 雲端硬碟**新增一個試算表**，命名為「華暉出貨自動化」。
2. 打開日常作業用的主檔，在「出貨單」「貨運單」「廠商清冊」三個工作表的分頁上分別按右鍵 → **複製到 → 現有試算表** → 選「華暉出貨自動化」。
   複製過去後，把名稱裡的「…的副本」刪掉，改回原本的名稱。
3. 在「華暉出貨自動化」打開 **擴充功能 → Apps Script**：
   - 建立三個檔案 `Core.gs`、`Main.gs`，以及專案設定裡的 `appsscript.json`，分別貼上 repo 中 `apps-script/` 資料夾內同名檔案的內容。
   - `appsscript.json` 要先在「專案設定」勾選「在編輯器中顯示 appsscript.json」才看得到。
4. 在編輯器上方選擇函式 `setup` → 按「執行」→ 依照畫面完成授權（會要求試算表、雲端硬碟、寄信權限）。
5. 回到試算表重新整理，上方會多出「華暉出貨」選單。打開「設定」工作表，填入：
   - **通知Email**：例如三位管理員的信箱
   - **輸出資料夾ID**：建議新建一個資料夾，例如「出貨單輸出」
   - **主檔試算表ID**（建議填）：填了之後，每次產單前會自動同步主檔的廠商清冊
   - **單據編號月份**：`2026-11`；**單據編號最後流水號**：本月目前用到的號碼，例如 `47`
6. 在「假日」工作表填入國定假日和公司休假。

## 第一次測試（對應驗收標準）
1. 在「出貨清單」填 8 家店的測試資料：出貨日填今天，店家、型號用下拉選單選，再填數量。
2. 用選單「華暉出貨 → 產生今日主批次」。
3. 檢查：
   - [ ] 出貨單 PDF 共 8 頁（每家一頁，含兩聯），價格、稅額、合計和現在手動產出的一樣
   - [ ] 單據編號從「最後流水號 + 1」開始連號
   - [ ] 貨運單 PDF 共 3 頁（3 + 3 + 2），**用實體貼紙試印對位**
   - [ ] Email 有收到兩個 PDF 附件
   - [ ] 「出貨清單」的狀態變成 `已產單`，並填上批次和單據編號
4. 測完後把測試的訂單列刪除，並把「單據編號最後流水號」改回原本的號碼。

## 列印對位調整
「設定」工作表中的這幾項控制列印版面：
- `出貨單列印設定`、`貨運單列印設定`：預設為 A4、符合頁面、標準邊界（上下 0.75、左右 0.7 英吋）、靠左靠上，對應 Google 試算表「依分頁符號自動調整」的印法
- `出貨單列印列`（1-57）、`貨運單第一頁列`（1-41）、`貨運單第二頁列`（42-84）
- `貨運單列印欄數`：貼紙上的字印得比原本大，就改成 11；印得比原本小，就改成 9
- `出貨單清空欄位`：模板上手動輸入的欄位（折讓、已收金額），每張單產生前都會清空；要填的話請填在「出貨清單」最後兩欄「折讓金額」「已收金額」（同一家店填在任一列即可，多列會加總）
- **列印 PDF 時一律選「實際大小／100%」**，不要選「符合頁面」

## 需要實際測試確認的地方
1. 隱藏的列和欄不會出現在 PDF 裡（系統是用「隱藏」的方式只輸出 A～I 欄和指定的列）。
2. 貨運單上的圖片（寄件人資料）複製後仍然正常顯示。
3. 單據日期（H4 的 DATEVALUE 公式）在產出的檔案中顯示正確。

## 第二階段預備：訊息解析測試
- 「型號對照」工作表：客戶的說法 → 型號（例如「直流」→ DCB-6000、「A款」→ GPB-2000A、「8pin」→ DCB-6000 且為 8pin）。可以自行增修，例如之後補上工具品項。
- 「解析測試」工作表：在 A 欄貼上客戶訊息（同一位客戶的連續訊息貼在同一格），B 欄可填店家，傳了圖片就勾 C 欄，再執行選單「華暉出貨 → 解析測試」。
  - 系統會判斷：明確訂單／待確認／不是訂單，並列出品項、備註、需要確認的原因。
  - 只寫「小電池」「幫我出10+1」這類沒寫型號的訊息，有填店家的話會列出這家店上一筆訂單（出貨清單＋主檔「庫存管理」的出庫紀錄）當建議。
- 這一步只是測試，不會寫進出貨清單、也不會產單。

**重點發現**
1. 客服回覆幾乎都是**同一句範本**：「👌收到，{今天／明天／下週一}幫您安排出貨，謝謝老闆💕」，只有日期在變。
2. 回覆「今天」的時間落在 10:22–14:21，回覆「明天」的則是 16:14 之後的訂單。也就是說，**實際的當天出貨截止時間大約在下午**，跟需求單寫的 10:00 不一樣，要先確認。
3. 回覆有時延遲好幾個小時（16:14 → 21:26、18:18 → 隔天 10:22）。

## 2. Excel 觀察

1. **你們實際用的是 Google 試算表**：公式裡有小寫 `if`、`IFS`，使用說明寫「檔案→列印→下一步→網頁」。
   → 雲端可以直接寫進 Google 試算表，再匯出 PDF：版面和現在完全一樣、免費，**不需要辦公室電腦**。
2. **出貨單**：只要填 M3 客戶、L3 日期、H5 單據編號、C9:C15 型號、D9:D15 數量、H 欄附註（例如 `10+1/8P*2`），其他欄位都由公式帶出。**最多 7 行品項**。單價依廠商清冊的「價格組合」（A～I 共 11 種）決定，營業稅用 IFS 計算。
3. **單據編號**是手動輸入的（例如 `20BF10000000085`），使用說明寫「跨月份時記得更改單據編號」→ 由系統自動編號，規則要先確認。
4. **貨運單**：L3:L8 只有 **6 個店家欄位**（每頁 3 張，共 2 頁）。驗收要求 8 家，模板需要擴充到 9 格或更多。
5. **廠商清冊**有 199 家，但有重複店名（例如微霖科技出現兩次，VLOOKUP 只會抓第一筆）。LINE 上的名稱（例如「麒鎮車業/吾小吳」）和清冊上的名稱（「麒鎮車業行」）也不一樣。而且 LINE 後台幫客戶改的暱稱 **API 讀不到**，所以需要做一次 LINE 帳號和店家的綁定。

## 3. 對策：Webhook 讀不到客服回覆

### 根本做法：讓系統代替客服發「收到，X 幫您安排出貨」
既然回覆都是固定範本，就讓系統來發。**系統自己發出的承諾，系統一定知道**，問題就不存在了。

```
客戶下單訊息
   │（等待約 30–60 秒，合併連續訊息）
   ▼
系統解析 ── 清楚（店家、品項、數量都確定，也沒有特殊要求）
   │          └─▶ 依截止規則決定今天或明天
   │              └─▶ 用 reply（免費）回覆客戶範本句，訂單入列
   │
   └── 不清楚（看圖、沒寫品項、有特殊時間要求、10+1 沒寫品項…）
              └─▶ 不回覆客戶；送卡片到管理群：
                  [今天] [明天] [下週一] [指定日期] [修改] [不是訂單]
                  └─▶ 管理員按下 → 系統記錄日期 → 系統把範本句推播給客戶
```

- 清楚的訂單：客服**完全不用動手**，客戶也更快收到回覆。
- 異常的訂單：客服本來就要回覆，現在只是從「打字」變成「按一下」。
- 推播額度：只有異常訂單才用 push，大約每天 1 則，遠低於每月 200 則的上限。

### 保留人工回覆的空間（過渡期／特殊情況）
- 卡片多一顆 **[我已手動回覆]**：客服照舊在後台打字，打完在卡片上點一下日期，系統就會記錄。
- 管理群指令：`#出貨 微霖 下週一`，系統用免費的 reply 回覆確認。
- **安全網**：每天 09:30 把「有訊息但還沒成單或還沒回覆」的對話列成一張清單，避免漏單。

### 評估過但不建議的做法
| 做法 | 不建議的原因 |
|---|---|
| 用程式模擬登入 LINE 官方帳號後台、抓聊天紀錄 | 可能違反 LINE 使用條款，介面一改就壞，帳號有被停用的風險 |
| 讀客服手機的通知 | 通知只有「客戶傳來的訊息」，沒有客服回覆 |
| 只靠時間規則推算，不記錄客服回覆 | 像微霖「下週一」這種情況一定會漏 |

### 需要實測確認
1. reply token 的有效時間能不能撐過「等待合併訊息」的時間（預計等 30–60 秒）。
2. 「手動聊天」模式開啟時，Webhook 和 bot 回覆是否照常運作。
3. 截圖中**綠色泡泡**（沒有顯示管理員名字）是怎麼送出的（預約傳送？自動回應？）。

## 4. 需要公司確認的規則
1. **當天出貨的截止時間**（樣本顯示大約在下午，不是 10:00）；10:00 批次和下午出貨之間是什麼關係。
2. 週六日、假日下單怎麼算出貨日。
3. 單據編號的規則（例如 `20BF1` + 流水號？跨月怎麼重編？）。
4. 「10+1」是否自動適用（例如信耀訂 10 顆，要不要自動送 1 顆？）；客戶只說「10+1」沒寫品項時，預設哪個品項。
5. 簡稱對照：小電、小電池、2000 → GPB-2000 還是 A／S 款？直流 → DCB-6000 4pin？
6. 「工具」是什麼品項（T27 五角批頭、L 型螺絲起子、小電池工具組？）、怎麼計價；「不需要工具」的預設值。
7. 「記下個月帳」「要統編發票」「午後收貨」這類備註要寫在出貨單的哪一欄。
8. 綠色泡泡的發送方式。
